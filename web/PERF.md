# Производительность

Граф использует готовые координаты `preset`, индексы/фильтрация выполняются пакетно, а Cytoscape скрывает рёбра во время перемещения. Для репрезентативного замера откройте DevTools Performance с фактическими 2 248 узлами / 3 119 рёбрами: целевые бюджеты — первая отрисовка < 1,5 с и фокус < 1 с. В демо-наборе отрисовка завершается в один кадр.
