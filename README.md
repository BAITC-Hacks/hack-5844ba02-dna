# DNA — «Граф денег»

Репозиторий команды DNA для хакатона HackAlem AI. Кейс посвящён восстановлению финансовой структуры по графу внутрибанковских переводов: определению ролей участников, выделению кластеров и приоритизации узлов для анализа.

## Содержимое репозитория

- [Описание датасета](dataset%204.md) — схема данных, параметры сбора и ограничения выборки.
- [Данные](data/) — узлы (`nodes.parquet`), агрегированные переводы (`edges.parquet`) и отдельные транзакции (`transactions.parquet`).
- [Стартовый код](starter/starter.py) — загрузка и проверки данных, построение направленного взвешенного графа, расчёт базовых метрик и создание CSV-заготовок.
- [Инструкция по запуску](starter/README.md) — установка зависимостей, запуск и требования к результатам. Команды из раздела «Запуск» выполняются из папки `starter/`.

## Ожидаемые результаты

| Файл | Содержимое |
|---|---|
| `nodes_roles.csv` | Роли всех 2 248 узлов и численные обоснования |
| `clusters.csv` | Кластеры и гипотезы об их назначении |
| `top_nodes.csv` | Не менее 20 узлов, отсортированных по приоритету |

Стартовый код создаёт заготовки: присвоение ролей, кластеризацию и ранжирование необходимо реализовать отдельно. Подробные требования к колонкам и заполнению приведены в ТЗ и [инструкции](starter/README.md#требования-к-выгрузкам).

## Ограничения данных

Граф собран от seed-клиентов по исходящим переводам до четырёх колен. Отсутствие исходящих рёбер на границе выборки не доказывает, что деньги осели у участника, а входящий оборот seed-клиентов может быть неполным. Эти ограничения нужно учитывать при интерпретации метрик и назначении ролей.
